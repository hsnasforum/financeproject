## 변경 이유

- 2026-07-16에는 통과했던 npm Bulk Advisory 감사가 2026-07-20 이후 공개된 권고 31건 때문에 PR #270 재실행에서 실패했습니다.
- 릴리즈 보안 게이트를 낮추지 않고 취약 의존성을 수정 버전으로 올린 뒤 실제 게시일과 보안 변경을 v1.0.5 릴리즈 노트에 반영할 필요가 있었습니다.

## 핵심 변경

- Auth.js를 `next-auth 5.0.0-beta.32`, `@auth/core 0.41.3` 경로로 맞추고 `@auth/prisma-adapter 2.11.3`으로 갱신했습니다.
- Next.js와 ESLint 설정을 `16.2.12`, Prisma Client·adapter·CLI를 `7.9.1`로 맞췄습니다.
- `brace-expansion`, `fast-uri`, `js-yaml`, `postcss`, `sharp`를 공개 권고의 수정 버전 이상으로 고정하고 취약한 Hono·Valibot 전이 경로를 제거했습니다.
- v1.0.5 실제 릴리즈일을 `2026-08-02`로 갱신하고 보안 의존성 정비 내용을 CHANGELOG와 릴리즈 노트에 추가했습니다.
