## 변경 이유

- 실제 GitHub Release가 `v1.0.4`에서 멈춘 상태라 `v1.0.4` 이후 누적 변경을 현재 `main` 기준 `v1.0.5`로 게시할 필요가 있었습니다.
- 과거 커밋에 `v1.1.0`~`v1.4.0` 태그를 소급 생성하면 당시 package version과 현재 release source guard가 어긋나므로, 다섯 구간은 회고 문서로 유지하고 실제 태그는 `v1.0.5` 한 건만 준비했습니다.
- npm registry가 pnpm 9·10이 사용하는 기존 audit endpoint를 HTTP 410으로 종료해 동일한 상태로는 로컬과 GitHub Actions의 `release:verify`가 모두 실패했습니다.
- pnpm major upgrade 대신 `pnpm-lock.yaml`의 정확한 패키지 버전을 Bulk Advisory API로 조회하는 fail-closed audit 경로와 계약 테스트를 추가했습니다.

- dependency audit는 lockfile의 625개 패키지·649개 버전을 Bulk Advisory API에 조회하며 응답 실패·형식 오류·advisory 존재 시 실패하도록 변경했습니다.
- audit parser, advisory 정렬, 실패 응답과 정상 응답 계약 테스트 3개를 추가했습니다.
