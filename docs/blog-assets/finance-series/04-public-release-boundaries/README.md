# 파이낸스 검증 4편 이미지 사용 명세

## 제작 원칙

- 실제 코드와 `/work` 기록을 중심으로 사용하고, 형광펜·테이프·짧은 메모만 설명 요소로 추가했습니다.
- 6개 이미지 모두 데스크톱 본문용 1200×700 PNG이며 브라우저 UI가 없는 부분 캡처 형식입니다.
- 로컬 사용자명, 절대 경로, API 키, 토큰, 실제 사용자 데이터와 저장소 주소를 포함하지 않습니다.
- 완벽하게 정렬된 인포그래픽보다 사람이 검토하면서 표시한 작업 노트처럼 보이도록 카드 기울기와 메모 배치를 조금씩 다르게 했습니다.
- 설명용 메모는 실제 코드·작업 기록과 구분했으며, 존재하지 않는 터미널 출력이나 실행 결과를 만들지 않았습니다.

## 원고 표현 주의

- IMAGE_06의 두 구현은 같은 복원 경로가 아닙니다. 일반 Planning 백업·복원 코드가 존재하므로 “복원 전체가 막혀 있다”라고 쓰면 범위가 과도합니다.
- 원고에서는 `v3:restore --apply` 또는 `v3 owner restore apply`가 차단돼 있다고 범위를 좁혀야 이미지와 현재 코드가 일치합니다.
- IMAGE_05의 원격 Release 상태는 2026년 7월 16일 조회 기준입니다. 최신 상태로 재사용하지 않으며, 새 이미지가 필요하면 현재 Release를 다시 조회해 별도 근거로 생성해야 합니다.
