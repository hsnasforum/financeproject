## IMAGE_05 제외 사유

- 원고의 “2026년 7월 12일 릴리스 후보 E2E 38건 통과”를 직접 증명하는 동일 실행 기록을 확인하지 못했다.
- 확인된 7월 12일 `/work` 기록에는 RC E2E `26 passed / 1 skipped` 결과가 남아 있어 38건 기록과 일치하지 않는다.
- 두 `release:verify` 기록의 실행 시각과 순서도 확인되지 않아 서로 다른 결과를 한 화면으로 합성하지 않았다.
- 따라서 IMAGE_05는 선택·조건부 이미지로 남기고 PNG를 생성하지 않았다.

## 캡처 및 검수

- 2026-07-14 당시 로컬 캡처 작업은 화면값이 fixture의 106,619원과 다르면 캡처 전에 실패하도록 구성했다.
- 당시 생성 스크립트는 이후 바뀐 화면·테스트 계약에 의존해 재현 가능하지 않으므로 게시 대상에서 제외했다. 갱신 절차는 상위 `README.md`의 보관 정책을 따른다.
- 설명 이미지는 실제 fixture·코드·테스트 파일을 읽고 핵심 값과 구문을 assertion한 뒤 생성한다.
- 5개 PNG 모두 1200×700 RGB이며 요소 overflow와 텍스트 clipping 검사를 통과했다.
- 저장 파일을 직접 열어 글자 잘림, 로딩 중 화면, 팝업, 불필요한 여백과 민감정보 노출이 없음을 확인했다.
- 화면 캡처에는 검증용 이름과 fixture 값만 사용했으며 실제 프로필, API 키, 토큰, 사용자명, 절대 경로와 데이터베이스 정보가 없다.
- 390×844 모바일 QA에서는 문서 폭이 510px로 렌더링되어 가로 120px 넘침이 확인됐다. 이번 블로그 이미지는 데스크톱용이므로 공개 PNG에는 영향이 없지만 모바일 UI에는 후속 개선이 필요하다.

## 원고 반영 시 주의

- 2026년 7월 14일 이미지 재현 과정에서 관련 테스트 두 파일을 다시 실행했고 `2 files / 8 tests PASS`를 확인했다. 원고의 “두 파일만 따로 실행한 최신 출력은 확보하지 못했다” 문장은 현재 상태에 맞게 수정해야 한다.
- `simulateAmortizingPayoff`는 반올림 전 이자를 합산한 뒤 총이자 79,423원을 반환한다. 반면 `buildAmortizationSchedule`의 월별 표시용 이자를 단순 합산하면 79,424원이므로, 원고의 “원 단위 총이자는 같았다” 문장은 어느 집계 기준인지 명시하는 편이 정확하다.
